KiriVers自托管软件更新服务

发布产物；应用检查并下载更新。官方二进制已内嵌管理台。

安装
管理台快速上手
SDK

  • 双平面

    单进程监听客户端平面（默认 :8080）与管理平面（默认 :8081）。

  • 原生 JSON 与商店 feed

    自制客户端走 POST 检查更新；Electron / Sparkle 等读商店 listing URL。

  • PostgreSQL 必需

    Redis 可选。cache.driver=redis 时启动必须 Ping 成功，否则进程不监听。
