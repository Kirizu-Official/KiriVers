# Audit log

Nav **Audit Log**. Description: “Project operation feed from the backend audit API.” Rows are written **after** a successful admin action. A write failure does not block the primary operation.

1. Open **Audit Log**.
2. Filter by **Time**, **Actor**, **Action**, **Target**.
3. **Details** may include Markdown. Use it to trace publishes, members, channels, and token changes.
