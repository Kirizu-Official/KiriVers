# 项目概览

导航 **概览**。项目列表卡片与详情展示聚合 `stats`：最新版本、版本数、**7 日活跃**、`storage_bytes`。响应**不含**设备哈希；卡片数据来自列表/详情接口，不必再逐张拉版本列表。

1. **项目管理** 打开 **项目列表**，可按名称或 Slug 搜索。
2. 点 **进入项目**。
3. 在 **概览** 查看饼图 **国家分布**（标签随当前界面语言取自融合后的 GeoIP 名称；行政区 ISO 不是国家码）、时序 `GET .../stats/series`。
4. 从本页进入 **设置**、**渠道管理**、**平台矩阵**、**版本管理**、**公告** 等子页。

概念：[遥测与设备](/guide/features/telemetry)。国家图依赖 [GeoIP](/admin/geoip)。
