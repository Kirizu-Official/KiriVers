# 灰度发布

版本页进入 **灰度**。机制是设备白名单 + **覆盖率旋钮**，**不是** HMAC / `rollout_percent`。关键版本界面：「关键版本不能进入增量灰度。」→ <ErrorCode code="GRAY_NOT_ALLOWED_ON_CRITICAL" />。

1. 打开某已发布版本的 **灰度**。
2. 设置 **起始 %**、**增量 %**、**间隔（秒）**。改旋钮**不**重置开始时间。
3. 点 **添加客户端**，勾选名册后 **加入所选**。表 **已进入灰度的客户端** 来源为 **自动放号** 或 **手动白名单**。
4. 需要立刻对匿名与商店 feed 可见时点 **立即全量**（写入 `gray_completed_at`）。

| 状态 | 未入名单（含匿名） |
|------|--------------------|
| 灰度未完成 | 仍见旧版；check/feed `Cache-Control: private` |
| 已全量 | 可见 |

空名册一开始即完成。`device_id_policy=none` 无法按设备放号。概念：[功能指南 · 灰度](/guide/features/gray)。
