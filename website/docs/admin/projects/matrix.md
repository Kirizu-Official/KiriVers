# 平台矩阵

导航 **平台矩阵**。每一行是 `(os, arch)` 加 **产物形态**（**单文件** / **多文件**）。操作系统 / 架构组合框使用 catalog slug（darwin 等别名存为 macos），不要把显示名当标识。

1. 打开 **平台矩阵**。
2. 点 **登记平台**。
3. 选择或输入 **操作系统**、**处理器架构**，选择 **产物形态**、可选 **默认差量算法**、**差量源版本数**、**硬件变体策略**、**最低系统**、**最低 API 级别**、**回退架构**。
4. 该平台已有**已发布**版本线后不能改形态（<ErrorCode code="PACKAGE_TYPE_IMMUTABLE" />）。界面：「该平台首次发布后产物形态不可更改。」

形态决定增量路径：单文件可走二进制差量；多文件走 pack。概念：[功能指南 · 平台矩阵](/guide/features/matrix)。
