# Directory Structure

Admin console lives in `frontend/` (Vue 3.5 + Vite 8 + Vuetify 4). `@` aliases `frontend/src`.

---

## Module Organization

| Kind of change | Where it goes |
|----------------|---------------|
| New console page | `src/pages/...vue` matching the URL. Nested project UI under `pages/projects/[projectRef]/`. |
| Shared dialog / chip / header | `src/components/`. Example: `ConfirmDialog.vue`, `ErrorAlert.vue`, `UploadDialog.vue`. |
| New HTTP call | Import the generated method and types from `@/api/generated` (admin) or `@/api/generated-client` (check / integrity / announcements preview). Unwrap list envelopes at the call site. Never a `/api/v1/` string in a page. |
| New SDK operation | Fix the owning plane spec (`openapi.admin.json` or `openapi.client.json`) if the handler JSON drifted, then `yarn generate:api`. Do not wrap the new method in a handwritten endpoint module. |
| Session / theme / toast / in-flight jobs | existing Pinia store. Do not add a new store for one page's form. |
| User-visible string | both `locales/zh-CN.ts` and `locales/en.ts` (`errors.<CODE>` for API codes). |
| Preset OS/arch lists | `src/constants/platforms.ts`. Combobox merge lives in `components/platformCatalog.ts`. |

`pages/login.vue` is the only `definePage({ meta: { layout: 'blank' } })` route. Everything else uses `DefaultShell` via `App.vue`.

Client-plane preview (check / integrity / announcements) imports `@/api/generated-client`. Vite must proxy `/api/v1/projects` before `/api` (see `quality-guidelines.md`).

`client.ts` is the only handwritten API module: Axios interceptors, `ApiError`, `registerAuthHooks`. It configures the admin generated client first (`baseURL`, `throwOnError: true`, interceptors on `client.instance`) then `clientPlane.setConfig({ axios: client.instance, baseURL, throwOnError: true })`. `main.ts` imports `@/api/client` before plugins so interceptors exist before any store/page request.

## Naming Conventions

- Pages: file-route names (`[projectRef].vue`, `[version].vue`).
- Components: PascalCase `.vue`.
- Composables: `useXxx.ts`.
- Pinia ids: `'auth' | 'ui' | 'jobs' | 'snackbar'`.
- JSON / API fields: snake_case, matching Go `public*` JSON and generated types.

---

## `frontend/AGENTS.md` vs this tree

`AGENTS.md` forbids hand-editing generated SDK dirs (`generated/`, `generated-client/`). Plane OpenAPI JSON is maintained in `internal/controller/`. `client.ts` is the maintained transport layer. Domain types and HTTP methods come from the generated SDKs.

---

## Forbidden

- New page that `fetch()`es or hardcodes `/api/v1/...`.
- Reintroducing `api/endpoints/`, `api/paths.ts`, handwritten `api/types.ts`, or `rawRequest`.
- Adding `src/mocks/`, `VITE_USE_MOCK`, or a DevPanel.
- Putting project CRUD next to `stores/app.ts` — that file is an empty Vuetify scaffold leftover; do not extend it.
- Hand-editing `src/api/generated/` or `src/api/generated-client/` after `yarn generate:api`.
