快速上手 ​

前提：已经安装，并且按 管理员初始化 能登录管理后台。本页从登录成功之后开始。其它按钮先跳过。目标：版本列表状态为 已发布。

控制台地图：全局抽屉里，平台管理员可见 管理员用户 / GeoIP / 节点；全体可见 项目管理。账号安全在右上角用户菜单 账号安全（/security），不是抽屉项。任务在顶栏铃铛（任务中心），没有独立「任务」路由。

  1. 项目管理 → 新建项目。填写 项目名称、Slug、比较引擎（语义化版本 或 整数构建号）。
  2. 进入项目 → 平台矩阵，点 登记平台：操作系统、处理器架构、产物形态（单文件 或 多文件）。
  3. 版本管理 → 创建版本，填写 构建号 或 SemVer，渠道先用 stable。
  4. 打开该版本 产物管理，点 上传产物，用普通文件选择上传安装包。direct_s3 恒为 false，不会对未知 S3 键做裸 PUT。
  5. 对该平台线点 标记就绪，再点 发布。
  6. 版本列表状态为 已发布 即成功。下一步让应用 检查更新。

发布拒绝：

  • ARTIFACT_REQUIRED发布被拒绝：没有任何就绪的版本线
  • AUTO_PUBLISH_PENDINGauto_publish_when 尚未全部就绪
  • UPLOAD_INCOMPLETE上传未完成，不能发布或标记就绪

概念：版本发布。点击细节：版本。
