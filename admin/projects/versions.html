版本 ​

导航 版本管理。生命周期：草稿 → 标记就绪 → 发布 / 弃用 / 吊销。版本线 撤下（yank）、停用。渠道晋升 到更稳渠道。

创建与发布 ​

  1. 点 创建版本。填 构建号 和/或 SemVer、渠道。stable 不能用预发布后缀（CHANNEL_SUFFIX_MISMATCHSemVer 预发布后缀与渠道不一致；stable 不能用预发布后缀）。同号占用 VERSION_ALREADY_EXISTS同项目版本号占用。引擎与标识不符 ENGINE_MISMATCH比较引擎与版本标识不匹配。
  2. 可选 长期支持（LTS）、关键版本（强制全员）、最低直升来源。关键版本不能走灰度（GRAY_NOT_ALLOWED_ON_CRITICAL关键版本禁止灰度）。
  3. 打开 产物管理。点 上传产物，通道可选 一次性直传 或 TUS 分片（可续传）。direct_s3 恒为 false：禁止对未知 S3 键裸 PUT。声明哈希不符 CHECKSUM_MISMATCH声明 SHA-256 与服务端复算不符。未登记 hw → HW_REV_UNKNOWN未登记硬件代号。已发布产物不可覆盖（ARTIFACT_IMMUTABLE已发布产物不可覆盖（先 yank 版本线），先 撤下（yank））。
  4. 对该平台线点 标记就绪。上传未完成 → UPLOAD_INCOMPLETE上传未完成，不能发布或标记就绪。
  5. 点 发布。没有任何就绪版本线 → ARTIFACT_REQUIRED发布被拒绝：没有任何就绪的版本线。auto_publish_when 未齐 → AUTO_PUBLISH_PENDINGauto_publish_when 尚未全部就绪。界面「发布后更新日志不可修改」。
  6. 差量 生成差量、产物 复用已有产物、多文件打归档为异步 Job（顶栏 任务中心）。失败 JOB_FAILED异步任务失败。

列表 latest=true ​

管理 GET versions?latest=true&os=&arch= 返回 { versions, latest }。latest 是已发布且线 ready、用 CompareVersions 算出的，不是客户端 SelectTarget。无 latest 查询时响应不含 latest。

概念：功能指南 · 版本发布。CI：自动发版。
