# KiriVers Go client SDK

本分支是**跳转**，不含包源码。Go modules 要求仓库根等于包根，不能从本仓 `main` 或本分支 `go get`。

- 发布仓 / 模块路径：https://github.com/Kirizu-Official/KiriVers-SDK-Go  
  (`github.com/Kirizu-Official/KiriVers-SDK-Go`)
- 本仓完整源码（开发与测试，不可 `go get`）：`sdk/go-src`

```text
go get github.com/Kirizu-Official/KiriVers-SDK-Go@latest
```

独立仓尚未创建时，从 `sdk/go-src` 拷到新仓根目录再打 `v0.1.0`。步骤见默认分支 [`docs/sdk-publish.md`](https://github.com/Kirizu-Official/KiriVers/blob/main/docs/sdk-publish.md)。
